# Layers studies

Open `/layers/` on the V3 preview server and use the review bar:

- `checklist.html`: compact checklist.
- `switches.html`: on/off switches.
- `tiles.html`: visual layer tiles.

Each uses the real layer drawing handlers, session-only samples and a fixed document-level overlay excluded from automatic map framing. The popup supports the trigger, Close, Escape, outside dismissal and keyboard input. **01 Checklist is approved and integrated into the main interface**, using shared `../layers.css` and `../layers.js`. These studies preserve the three proposals for reference.

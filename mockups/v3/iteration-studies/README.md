# Iteration workflow mockups

Open [the overview](index.html).

- **Selective regeneration:** retains region/area/tile selection and adds Reroll, Variation and text-labelled Keep checkboxes. The resources example previews real deposit relocation inside the selection; vegetation/relief illustrate existing adjustments. This is not a new constrained generation engine. Global changes keep their existing behavior.
- **History & projects:** a compact panel supports All/Bookmarked filtering, finding a version and comparing prepared versions using Original/Version/Changes. Use version restores the selected snapshot. Open/Save project dialogs show the proposed placement and contents; no project file is read or produced.

Both use session-only prepared maps and the approved production styles. They do not access persistent history or add these workflows to the main app.

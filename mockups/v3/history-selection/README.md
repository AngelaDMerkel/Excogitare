# Selected snapshot studies

[Compare the three options](index.html), then open a mockup and select different thumbnails:

1. **Corner marks** — four navy corners identify the active map while leaving its preview clear. Recommended for a clear selection with little added decoration.
2. **Soft highlight** — a tinted backing gives the selected map more weight; other previews are quieter.
3. **Selection tick** — a navy check badge identifies the active map at the lower left, clear of the bookmark and download controls.

Gold still means bookmarked. Navy indicates the map currently being viewed. All three retain the approved hover controls, 88×52px thumbnails and lower fade. The native pressed state and keyboard focus remain available.

These pages use prepared sample maps with session-only history. Production styling and saved history are unchanged.

Approved **01 Corner marks** is integrated in the main application and active aliases. These studies remain available for comparison.
